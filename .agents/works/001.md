---

## 1. Tujuan

- Klasifikasi yang **konsisten** — saat ini bercampur "berdasarkan platform" (linux, mysql, couchdb) dan "berdasarkan kegunaan" (fs, network, git).
- **Script platform-spesifik** punya rumah jelas: `tux/` (Linux), `win/` (Windows).
- **Script serbaguna/standalone** berkumpul di `kits/`.
- **Library bersama** jelas terpisah dari script sekali-pakai.
- Aplikasi besar (gallery) terisolasi & self-contained.
- **Kedalaman folder maksimal 2 level** (di luar isi internal `apps/`).
- Mengurangi sampah di root dan file sisa (`.tmp`, folder kosong).

## 3. Definisi kategori (final)

| Folder | Peran | Sifat | Contoh yang cocok |
|--------|-------|-------|-------------------|
| `libs/` | Kode yang **di-`require`/di-import** file lain | Tidak dijalankan langsung | `arguments.php` |
| `kits/` | **Script standalone serbaguna** (lintas-platform) | Dijalankan langsung; bukan app, bukan platform-spesifik | `file-hasher.php`, `duplicate-finder.php` |
| `dev/` | **Script kerja programmer harian** lintas-platform | git, editor, db | `git-repo-lite.py` |
| `tux/` | Script **khusus Linux** | Butuh Linux (xinput, Xvfb, Wine, dsb.) | `xvfb-simple.sh`, `cleanup1.sh` |
| `win/` | Script **khusus Windows** | PowerShell / batch | `PHPServer.ps1`, `merge-*.bat` |
| `apps/` | **Aplikasi penuh** dengan UI/server sendiri | Self-contained, punya README/AGENTS sendiri | `gallery/` |
| `devices/` | Script perangkat input/display | Keyboard, touchpad | `touchpad-toggle.sh` |

### Aturan keputusan (decision tree)

```text
Kode ini di-require / di-import file lain?
├─ Ya  → libs/
└─ Tidak → dijalankan langsung sendiri?
   ├─ Ya
   │  ├─ Khusus Windows?                     → win/
   │  ├─ Khusus Linux?                        → tux/
   │  ├─ Perangkat input/display?             → devices/
   │  ├─ Bagian workflow kerja programmer?    → dev/
   │  ├─ Script serbaguna standalone?         → kits/
   │  └─ Aplikasi dengan UI/server?           → apps/
   └─ Tidak → (jarang) taruh di libs/
```

## 6. Aturan konvensi

1. **Kedalaman folder maksimal 2 level** (di luar `apps/`). `apps/` bebas.
2. **Script platform-spesifik** → `tux/` (Linux) atau `win/` (Windows). Jangan campur.
3. **Script standalone serbaguna** → `kits/`.
4. **Script kerja harian lintas-platform** → `dev/`.
5. **Perangkat input/display** → `devices/`.
6. **Kode yang di-`require`/`import`** → `libs/`.
7. **Aplikasi dengan UI/server** → `apps/<nama>/`, entrypoint `index.php` / `main.*`.
8. **Satu app = satu AGENTS.md/README.md** di dalam foldernya.
9. **Satu sumbu per level**: *platform* (`tux`, `win`) atau *peran* (`kits`, `dev`, `libs`, `apps`, `devices`).
10. **Nama file deskriptif**, kebab-case (`duplicate-finder.php`, `git-repo-lite.py`).
11. **Beri ekstensi yang benar** untuk executable. Hindari file tanpa ekstensi.
12. **Docs**: `README.md` & `CHANGE.md` di root.
13. **Bersihkan artefak**: hapus folder kosong & `*.tmp`.
14. **Submodule** (`couchdb/dump`): jangan dipindah.
